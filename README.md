# Что болит

Веб-приложение на Flask для учета пациентов, медицинских вызовов и лекарств. Данные хранятся в SQLite; SQLAlchemy позволяет перейти на PostgreSQL заменой `DATABASE_URL`.

## Задание

Приложение использует для работы коллектив врачей. В базу данных
должны быть занесены имя, пол, дата рождения и домашний адрес каждого
их пациента. Всякий раз, когда врач осматривает больного, явившегося к
нему на прием, или сам приходит к нему на дом, он записывает дату и место,
где проводится осмотр, симптомы, диагноз и предписания больному,
проставляет имя пациента, а также свое имя. Если врач прописывает
больному какое-либо лекарство, в базу заносится название лекарства, способ
его приема, словесное описание предполагаемого действия и возможных
побочных эффектов.
Написать приложение, поддерживающее следующий функционал:
1) по заданной дате определить количество вызовов в этот день;
2) позволяют определить количество больных, заболевших данной
болезнью;
3) по заданному лекарству определить его побочный эффект порядке;
4) предоставить возможность добавления нового лекарства с
описанием его свойств.

## Установка и запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000.

## Структура

- `what_hurts/` — пакет приложения, модели, формы, декораторы и маршруты.
- `what_hurts/routes/` — аутентификация, пациенты, вызовы, лекарства, отчеты и администрирование.
- `what_hurts/templates/` — Jinja2-шаблоны интерфейса.
- `what_hurts/static/css/style.css` — адаптивные стили.
- `init_db.py` — создание таблиц и тестовых данных (пересоздает БД).
- `app.py` — точка входа.

## Руководство по ролям

- **Врач:** просматривает пациентов и лекарства, создает/редактирует пациентов, создает вызовы и редактирует только собственные вызовы, просматривает свои вызовы.
- **Аналитик:** просматривает пациентов, лекарства и все вызовы; формирует детальный отчет, сводку по врачам и CSV-экспорт.
- **Администратор:** имеет права аналитика, управляет пользователями и лекарствами, просматривает последние 100 событий.

## Примечания

- Все рабочие разделы требуют входа; формы защищены CSRF.
- После пяти неверных паролей учетная запись блокируется на пять минут.
- Сессия ограничена 30 минутами.
- Журналируются входы/выходы, неудачные входы, создание/изменение вызовов и добавление лекарств.
- Для смены БД задайте `DATABASE_URL`, например `postgresql+psycopg://user:password@localhost/what_hurts`, и установите драйвер PostgreSQL.
